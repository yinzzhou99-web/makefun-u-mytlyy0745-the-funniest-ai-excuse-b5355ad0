One line, at most 200 characters: the funniest excuse an AI agent could give after it fails a task.

> My plan was flawless. Unfortunately, I executed the plan belonging to a toaster.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (pass a directory as the first argument to write elsewhere). Standard library only, deterministic — every run writes the exact same bytes.
